# Классификация тональности SST-2 с помощью BERT

Домашнее задание по NLP: бинарная классификация тональности предложений
на датасете **SST-2** (Stanford Sentiment Treebank) с использованием
предобученной модели `bert-base-uncased`.

## Подход

BERT используется как **замороженный экстрактор признаков**, а не дообучается:

1. Каждое предложение токенизируется (`max_length=128`, паддинг до длины батча).
2. Прогоняется через `bert-base-uncased` в режиме инференса (`eval` + `torch.no_grad`).
3. В качестве представления берётся `pooler_output` - эмбеддинг `[CLS]`-токена
   размерности 768, пропущенный через линейный слой с `tanh`.
4. Поверх полученных признаков обучается логистическая регрессия на PyTorch
   (`nn.Linear(768, 1)` + `BCEWithLogitsLoss`, оптимизатор Adam, full-batch).

## Данные

| Выборка | Размер | Источник |
|---------|--------|----------|
| train   | 5000   | первые 5000 строк `SST2/train.tsv` |
| test    | 1920   | оставшиеся строки того же файла |
| holdout | 500    | отдельный `texts_holdout.json` |

Оба файла скачиваются автоматически при запуске ноутбука.

## Результаты

| Метрика | test |
|---------|------|
| accuracy | ≈ 0.85 |
| roc-auc  | ≈ 0.92 |

Целевой порог задания - **84.5% accuracy** на тестовой части — пройден.

## Структура ноутбука

1. **Подготовка окружения** - импорты, константы, фиксация сидов, выбор устройства.
2. **Загрузка данных** - train/test/holdout, проверка размеров и баланса классов.
3. **Извлечение эмбеддингов** - функция `get_embeddings`, батчевый прогон, кэш в `embeddings.pt`.
4. **Классификатор** - класс `LogisticRegression`, функция `train_model`.
5. **Оценка качества** - `predict_proba`, `evaluate`, проверка порога, вероятности для всех выборок.
6. **Выводы** - что получилось и что можно улучшить.
